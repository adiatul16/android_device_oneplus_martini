Device configuration for OnePlus 9RT
=========================================

The OnePlus 9RT (codenamed _"mt2110/mt2111"_) is a premium mid-range smartphone from OnePlus.

It was announced in October 2021 (China) and January 2022 (India).

## Device specifications

Basic   | Spec Sheet  
-------:|:-------------------------  
CPU     | Octa-core (1x2.84 GHz Kryo 680 & 3x2.42 GHz Kryo 680 & 4x1.80 GHz Kryo 680)  
Chipset | Qualcomm SM8350 Snapdragon 888 5G (5 nm)  
GPU     | Adreno 660  
Memory  | 8/12 GB RAM  
Shipped Android Version | 11.0 (ColorOS in China, OxygenOS in India)  
Storage | 128/256 GB (UFS 3.1)  
Battery | Non-removable Li-Po 4500 mAh  
Display | 2400 x 1080 pixels, 6.62 inches AMOLED, 120Hz (~397 ppi pixel density)  
Camera  | 50 MP wide (IMX766), 16 MP ultra-wide, 2 MP macro, dual-LED flash
